# Contributing to Syambot CLI

Thanks for your interest in contributing to Syambot CLI.

## Contribution Flow (Fork + PR)

1. Fork this repository to your GitHub account.
2. Create a new branch from the main branch for your changes.
3. Make the required changes.
4. Run checks before opening a PR:

```bash
npm run check
```

5. Commit with a clear and descriptive message.
6. Push your branch to your fork.
7. Open a Pull Request (PR) to the main repository.

## PR Description Checklist

When opening a PR, include:

- problem addressed
- main changes made
- test/validation steps already run

## Request Direct Collaborator Access

If you need direct collaborator access (instead of the fork flow), open an issue with label `collaborator-request` or contact the maintainer and include:

- your GitHub username
- why you want to join
- contribution area you want to focus on
