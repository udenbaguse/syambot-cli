# Contributing to Syambot CLI

Terima kasih sudah tertarik berkontribusi ke Syambot CLI.

## Alur Kontribusi (Fork + PR)

1. Fork repository ini ke akun GitHub kamu.
2. Buat branch baru dari branch utama untuk perubahanmu.
3. Lakukan perubahan seperlunya.
4. Jalankan pengecekan sebelum membuat PR:

```bash
npm run check
```

5. Commit dengan pesan yang jelas dan deskriptif.
6. Push branch kamu ke fork.
7. Buat Pull Request (PR) ke repository utama.

## Checklist Deskripsi PR

Saat membuat PR, sertakan:

- masalah yang diselesaikan
- perubahan utama yang kamu buat
- langkah test/validasi yang sudah dijalankan

## Request Akses Collaborator Langsung

Kalau kamu butuh akses collaborator langsung (bukan via fork), buka issue dengan label `collaborator-request` atau hubungi maintainer dan sertakan:

- username GitHub
- alasan ingin bergabung
- area kontribusi yang ingin kamu fokuskan
